# Staff Experience Checklist

Use this checklist while implementing the functions redesign to keep the experience simple, clear, and practical for staff.

## Core workflow
- [ ] A staff member can create a function in a few clear steps
- [ ] The main function screen is the primary place to work
- [ ] Core fields are easy to find and update
- [ ] Advanced details are available but do not overwhelm the screen
- [ ] Notes can be added quickly from the main screen
- [ ] Tasks can be created and updated without extra friction
- [ ] Quote building is possible without going into admin menus first

## Simplicity
- [ ] The screen does not feel cluttered
- [ ] The most common actions are obvious
- [ ] There are fewer unnecessary choices on the main screen
- [ ] The layout feels calm and focused
- [ ] The language is simple and operational

## Status and payments
- [ ] Function status is simple: Lead, Confirmed, Cancelled
- [ ] Deposit paid is easy to see and update
- [ ] Fully paid is easy to see and update
- [ ] Staff do not need to interpret a long list of statuses

## Quote and pricing
- [ ] Staff can add a room charge easily
- [ ] Staff can add food, drinks, extras, or services easily
- [ ] Staff can add a one-off item quickly
- [ ] Staff can save an item for reuse if they want to
- [ ] The quote page feels like a working sheet, not an admin configuration screen

## Notes and communication
- [ ] Notes can be added without opening a separate heavy editor
- [ ] Notes feel natural in the function workflow
- [ ] Communications remain easy to access

## Mobile and daily use
- [ ] The main flow works well on smaller screens
- [ ] Common actions are reachable without excessive scrolling
- [ ] The interface is still clear when used quickly during busy periods

## Overall experience
- [ ] A new staff member can understand the main workflow quickly
- [ ] The system feels faster than the current version
- [ ] The system feels more like a booking tool and less like an admin tool
- [ ] Staff can complete common tasks without needing to ask how to do them
